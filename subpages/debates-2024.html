¿De qué hablaron en los debates presidenciales 2024?

Este proyecto contiene el análisis de los transcritos de los tres debates presidenciales 2024. Me propuse responder una pregunta: ¿cuáles son las palabras que más repitió cada candidatura? A continuación te explico los pasos clave del proceso.

  • Python
  • requests
  • Regex
  • NLTK
  • pandas
  • seaborn

1. Obtención del texto del debate

Para obtener los transcritos, descargué la versión estenográfica de cada debate desde la página del INE (Instituto Nacional Electoral) utilizando la biblioteca requests. Luego, con expresiones regulares, extraje solo los párrafos del texto: 

res_1 = requests.get(url_1)   # Hacemos la solicitud a la página
html_1 = res_1.text            # Convertimos el resultado a texto

patron = r'<p>(.*?)</p>'     # Extraemos solo los párrafos

Aquí surge un reto: separar lo que dijo cada candidatura. Cada intervención inicia con su nombre en negritas, por lo tanto creé una expresión regular para cada una. Después limpié el texto para eliminar cualquier "residuo" del formato HTML (&nbsp;, etiquetas, signos de puntuación, etc.) y asegurarme de que solo se incluyeran las intervenciones de los candidatos. Por último, uní las intervenciones de los tres debates.

2. Procesamiento con NLTK

Para procesar el texto utilicé NLTK, un módulo de procesamiento del lenguaje natural. Los pasos fueron:

  • Tokenizar, es decir, separar el texto en palabras.
  • Eliminar las palabras comunes (stop words) como "el", "de" o "que", ya que no aportan información. Además agregué algunas que se repetían mucho en los discursos como "vamos", "tema" o "hacer".
  • Calcular la frecuencia de cada palabra y obtener el top 10.
tokens = word_tokenize(texto_candidato)
tokens = [palabra for palabra in tokens if palabra.lower() not in pc]
frecuencia = FreqDist(tokens)
frecuencia.most_common(10)   # Top 10 de palabras más repetidas

3. Visualización de resultados

Para visualizar los datos empleé pandas y seaborn. Creé un gráfico de barras para cada candidatura con el color de su partido o coalición, así podemos ver los resultados de manera clara y concisa.

Aquí podemos observar que "México" fue la palabra más repetida por las tres candidaturas. Además, "país" y "gobierno" aparecen en los tres top 10. A partir de ahí cada candidatura tiene palabras distintas, por ejemplo, menciones a sus contrincantes o a otros partidos.

¿Qué aprendí?

Este proyecto me permitió recorrer todo el proceso: desde obtener los datos directamente de una página web hasta procesar lenguaje natural. Algo que aprendí es que la mayor parte del trabajo está en limpiar el texto, es decir, sin una buena limpieza el análisis no funciona.

Por supuesto, contar palabras tiene sus limitaciones. Si analizáramos frases completas o el sentimiento de cada intervención, podríamos entender no solo qué se dijo, sino cómo se dijo.
